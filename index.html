关于本演示站

本页面旨在帮助你练习：使用 Git 管理静态页面代码，并通过 GitHub + Cloudflare Pages 实现自动化部署。

  1. 在本地编辑 HTML / CSS，实现你想要的布局与风格。
  2. 使用 Git 提交并推送到 GitHub 仓库。
  3. 在 Cloudflare Pages 连接仓库，完成构建和部署。
  4. 后续只需 push 代码，页面即可自动更新上线。
