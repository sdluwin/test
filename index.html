查看特点 了解部署流程

这个示例页面有什么？

纯静态

只包含 HTML 和 CSS，没有任何构建步骤，非常适合第一次部署练习。

响应式布局

在手机和电脑上都能良好显示，体现真实项目结构。

可自由扩展

你可以在此基础上添加更多页面、组件和样式，持续部署。

部署流程一览

  1. 在本地编辑这个页面，并用 Git 管理代码。
  2. 把代码推送到 GitHub 仓库。
  3. 在 Cloudflare Pages 连接这个 GitHub 仓库并部署。
  4. 以后只要 push 代码，Cloudflare 会自动重新部署。
